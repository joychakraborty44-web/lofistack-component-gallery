Campaign Performance Snapshot

A quick read of one ad campaign. Return on ad spend leads, shown against what was spent. Cost, reach and daily results sit beside it.

Example figures. Not real campaign data.

Status
Goal

Fields

name · platformCampaign name and ad platform.
statusactive, learning, paused or ended.
start · endDate range, YYYY-MM-DD.
spend · currencyTotal spend; any ISO currency code (default USD).
results · result-labelLead or conversion count, and what to call it.
cost · cost-labelOptional. Worked out as spend ÷ results. Shown as CPL for leads, CPA otherwise.
ctr · roasCTR in percent; ROAS as a multiple (4.2 = 4.2×).
seriesComma-separated daily results for the chart.
*-deltaOptional % change vs the previous period. A lower CPL/CPA shows as good.

Usage

<campaign-snapshot
  name="Campaign name"
  platform="Ad platform"
  status="active"
  start="2026-09-01" end="2026-09-24"
  spend="12480" currency="USD"
  results="386" result-label="Leads"
  ctr="1.84" roas="4.2"
  series="9,11,10,13,…">
</campaign-snapshot>

// or from data:
el.data = { name, platform, spend, results, roas, series: [...] };

Revenue is worked out as spend × ROAS. Every value can be updated live, and the card redraws itself.
