Lead Source Breakdown

Where leads come from, as a share of leads, revenue or spend. Point at a ring segment or a legend row to see its numbers. Hide a source and the rest add back up to 100%.

Example data. Not real client results.

Quarter

Fields

metricAttribute or JSON. leads (default), revenue or cpl. The switch updates it.
sources[]{ id, label, leads, revenue, spend }. Up to six; any more are folded into "Other".
sources[].hiddenOptional. Start with this source hidden.
eyebrow · title · periodOptional header text.
currency · localeISO currency (default USD) and number locale (default en-US).
sourceOptional footer note, e.g. where the data comes from.
labelsOptional. Override any built-in text, e.g. { "leads": "Enquiries" }.
--lsb-c1 … --lsb-c6CSS. The six source colours, in a colour-blind-checked order. Colour follows the source, not its rank.

In Cost per lead view the ring shows each source's share of spend. The centre shows the blended cost per lead: total spend over total leads.

Usage

<lead-source-breakdown metric="leads">
  <script type="application/json">
    {
      "title": "Where leads came from",
      "period": "Q3 2026",
      "sources": [
        { "id": "search", "label": "Paid search",
          "leads": 412, "revenue": 58400, "spend": 14420 },
        { "id": "email", "label": "Email",
          "leads": 118, "revenue": 17300, "spend": 590 }
      ]
    }
  </script>
</lead-source-breakdown>

// or from data:
el.data = { title, sources: [...] };
el.toggleSource("email");      // hide / show
el.showAll();
el.addEventListener("sourcetoggle", e => e.detail);

Hiding or showing a source fires sourcetoggle with the source, whether it is visible, and the visible ids. Changing the switch fires metricchange. Arrow keys step through ring segments; the legend is a real table.
