Activity Timeline

Everything that happened on a client account, newest first and grouped by day. Filter by type, open any event for its details, flip the order and load more as you scroll back.

Example data. Fictional client and people, not a real account.

Fields

sortAttribute. newest (default) or oldest. The sort switch updates it.
page-sizeAttribute. How many events show before “Show more” (default 8).
eyebrow · title · subtitleOptional header text.
nowOptional ISO date-time used for “Today”, “Yesterday” and “min ago”. Defaults to the current time.
events[].idUnique key. Used in events and to remember which items are open.
events[].typecall, email, form, deal or note. Sets the icon, colour and filter.
events[].timeISO date-time. Events are grouped by day and sorted by this.
events[].actorWho did it. Shown with initials.
events[].title · summaryHeadline and one-line description.
events[].detailsOptional [[label, value], …] pairs shown when the event is opened.
events[].noteOptional longer text, shown as a quote when opened.
typesOptional. Rename a type, e.g. { "form": "Form fill" }.
localeDate and time formatting locale (default en-US).

Usage

<activity-timeline sort="newest" page-size="8">
  <script type="application/json">
    {
      "title": "Brightside Dental",
      "events": [
        { "id": "a19", "type": "call",
          "time": "2026-10-02T14:05:00",
          "actor": "Luis Ortega",
          "title": "Discovery call",
          "summary": "Goals for new-patient bookings.",
          "details": [["Duration", "24 min"]] }
      ]
    }
  </script>
</activity-timeline>

// or from data:
el.data = { title, events: [...] };
el.filter = ["call", "email"];
el.addEventListener("activityopen", e => e.detail);

Opening an event fires activityopen with its id, type and title. Changing the type filters fires filterchange; the sort switch fires sortchange. el.expand(id) opens an event and el.collapseAll() closes them all.
