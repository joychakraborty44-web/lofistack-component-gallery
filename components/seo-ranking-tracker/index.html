SEO Ranking Tracker

Where a site ranks in search for each tracked keyword this week, how far it moved, and an eight-week history line. Sort any column, search, filter by rank, and open a row to see its full history.

Example data. Fictional sites and rankings, not real client results.

Client

Fields

keywords[].keywordThe search term being tracked.
keywords[].historyWeekly positions, oldest first. The last value is this week, the one before it is last week. Use null for "not in the top 100".
keywords[].urlThe page that ranks for the keyword.
keywords[].volumeAverage monthly searches.
keywords[].bestOptional all-time best. The lowest value in history is used if it is better.
keywords[].intentOptional tag, e.g. Local, Commercial, Brand.
weeks[]Labels for each history point, e.g. "Sep 25".
eyebrow · title · siteOptional header text.
period · sourceOptional date text (top right) and footer note.
sortAttribute. key:dir, where key is keyword, position, change, best or volume. Default position:asc.
filterAttribute. all, top3, top10, improved or declined.
labels · localeOptional. Override built-in text; number locale (default en-US).

Usage

<seo-rank-tracker sort="position:asc" filter="all">
  <script type="application/json">
    {
      "title": "Organic keyword positions",
      "weeks": ["Sep 18", "Sep 25", "Oct 2"],
      "keywords": [
        { "keyword": "emergency dentist near me",
          "url": "/emergency-dental", "volume": 6600,
          "history": [6, 5, 4] }
      ]
    }
  </script>
</seo-rank-tracker>

// or from data:
el.data = { title, weeks: [...], keywords: [...] };
el.addEventListener("keywordselect", e => e.detail);

Change, best position and the summary are all worked out from history. Opening or closing a row fires keywordselect with the keyword, position, change and URL. Sorting fires sortchange and filtering fires filterchange.
