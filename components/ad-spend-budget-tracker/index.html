Ad Spend Budget Tracker

Is each ad channel spending on pace this month? Each bar shows spend so far against today's ideal pace and the monthly budget. Edit a budget and the projections update straight away.

Example data. Fictional client, not real spend.

Fields

viewAttribute. spent (default) or projected. The switch updates it.
sortAttribute. default (data order) or used (highest % of budget first).
monthYYYY-MM. Sets the number of days in the month.
asOfYYYY-MM-DD, the day spend is counted to. Default: today.
channels[]{ id, label, budget, spent, icon }. Icon is search, social, video or display.
tolerance{ over, under } as fractions of budget (default 0.05 and 0.15). Projected spend outside this band is flagged.
eyebrow · titleOptional header text.
currency · localeISO currency (default USD) and number locale (default en-US).
sourceOptional footer note.
labelsOptional. Override any built-in text.

Ideal pace = budget × days so far ÷ days in month. Projected = spend so far ÷ days so far × days in month, so it assumes the current daily rate holds.

Usage

<ad-budget-tracker view="spent" sort="default">
  <script type="application/json">
    {
      "month": "2026-09",
      "asOf": "2026-09-18",
      "channels": [
        { "id": "search", "label": "Search Ads",
          "icon": "search", "budget": 12000, "spent": 7480 },
        { "id": "social", "label": "Social Ads",
          "icon": "social", "budget": 8000, "spent": 5620 }
      ]
    }
  </script>
</ad-budget-tracker>

// or from data:
el.data = { month, asOf, channels: [...] };
el.setBudget("social", 9500);
el.addEventListener("budgetchange", e => e.detail);

Click a budget to edit it: Enter saves, Esc cancels. Saving fires budgetchange with the channel, old and new budget, projection and status. The switch fires viewchange and the sort button fires sortchange.
