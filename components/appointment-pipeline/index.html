Appointment Pipeline

A week of bookings, one day at a time. Each appointment sits in a lane: Booked, Confirmed, Showed or No-show. Open one to move it to another lane or send a reminder, and the show rate updates as you go.

Example data. Fictional clients and phone numbers. Not real bookings.

Fields

dayAttribute. The date of the day to show. Defaults to today, then the first day.
eyebrow · title · subtitleOptional header text.
todayOptional YYYY-MM-DD. Marks that day with a "Today" tag.
days[].dateYYYY-MM-DD. Weekday and date labels are worked out from it.
days[].appointments[]One entry per booking, in any order. Sorted by time inside each lane.
…id · time · durationUnique key, HH:MM start (24-hour) and length in minutes.
…name · service · staffClient, appointment type and team member (shown as initials).
…statusbooked, confirmed, showed or noshow.
…remindedtrue once a reminder has gone out.
…source · phone · noteOptional details shown when an appointment is opened.
sourceOptional footer note.
labels · localeOptional. Override built-in text, and the locale for dates (default en-US).

Usage

<appointment-pipeline day="2026-09-30">
  <script type="application/json">
    {
      "title": "Downtown studio",
      "today": "2026-09-30",
      "days": [
        { "date": "2026-09-30", "appointments": [
          { "id": "c06", "time": "17:30", "duration": 45,
            "name": "Mia Thompson", "service": "Intro session",
            "staff": "Omar Baker", "status": "booked" }
        ] }
      ]
    }
  </script>
</appointment-pipeline>

// or from data:
el.data = { today, days: [...] };
el.setStatus("c06", "confirmed");
el.addEventListener("appointmentupdate", e => e.detail);

Moving an appointment or sending a reminder fires appointmentupdate with the appointment, the day and what changed (action is status or reminder). Picking a day fires daychange. setStatus(id, status) and remind(id) do the same from code.
