Revenue Growth Chart

Monthly revenue as an area chart, with the total and the change against the same months last year. Switch between 6 and 12 months, add last year as a dashed line, or show a running total. Hover the chart, or focus it and use the arrow keys, to read each month.

Example data. Not real client results.

Fields

rangeAttribute. 6m or 12m (default). The range buttons update it.
compareBoolean attribute. Shows last year as a dashed line with a legend.
cumulativeBoolean attribute. Draws a running total instead of monthly values.
eyebrow · title · subtitleOptional header text.
currencyAny ISO currency code (default USD). Attribute or JSON.
series[].monthMonth as YYYY-MM, oldest first.
series[].revenueRevenue for that month.
series[].lastYearOptional. Revenue for the same month a year earlier. Used for the growth figures and the dashed line.
sourceOptional footer note.
labels · localeOptional. Override built-in text, and the number and date locale (default en-US).

Usage

<revenue-growth-chart range="12m" compare>
  <script type="application/json">
    {
      "title": "Membership revenue",
      "currency": "USD",
      "series": [
        { "month": "2026-08", "revenue": 47900, "lastYear": 36200 },
        { "month": "2026-09", "revenue": 52400, "lastYear": 38900 }
      ]
    }
  </script>
</revenue-growth-chart>

// or from data:
el.data = { title, currency, series: [...] };
el.addEventListener("rangechange", e => e.detail);
el.replay();  // re-draw the line

The total, growth and averages are worked out from the series. Changing the range fires rangechange with the range, total and growth. The two toggles fire viewchange. A hidden table carries every value for screen readers.
