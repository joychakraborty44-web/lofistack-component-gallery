Notification Center

A bell with an unread count that opens a panel of mentions and system alerts. Switch tabs, open an item to mark it read, dismiss what you don't need, or clear everything at once.

Fields

openAttribute. When present the panel is open. The bell, Esc and clicking outside update it.
tabAttribute. all (default), mention or system.
title · nowPanel heading, and an optional ISO date-time used for “Today” and “min ago”.
footerOptional { label, href } link at the bottom. Without href it is a button that fires notificationfooter.
items[].id · typeUnique key, and mention or system (sets the tab).
items[].time · readISO date-time, and whether it has been read.
items[].actor · text · targetMentions: “Maya Chen mentioned you in Q4 plan”.
items[].title · iconSystem alerts: heading and icon (payment, warning, report, automation, integration).
items[].bodyOptional second line or quote.
items[].actionOptional { label, done } button. Fires notificationaction.
labels · localeOverride any built-in text; date formatting locale.

Usage

<notification-center tab="all">
  <script type="application/json">
    {
      "items": [
        { "id": "m1", "type": "mention", "read": false,
          "time": "2026-10-02T16:18:00",
          "actor": "Maya Chen", "text": "mentioned you in",
          "target": "Q4 plan" },
        { "id": "s1", "type": "system", "icon": "payment",
          "time": "2026-10-02T15:52:00",
          "title": "Payment received", "body": "Invoice #1043" }
      ]
    }
  </script>
</notification-center>

// or from data:
el.data = { items: [...] };
el.add({ type: "system", icon: "report", title: "Report ready" });
el.addEventListener("notificationread", e => e.detail.ids);

Opening an item marks it read and fires notificationread with its id; “Mark all as read” fires it once with every id in the current tab. Dismissing fires notificationdismiss. Use el.show(), el.hide(), el.toggle() and el.unread from code.
