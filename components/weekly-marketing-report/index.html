Weekly Marketing Report

A one-page weekly report laid out like a newspaper. It has a short summary, four key figures, highlights and lowlights, a channel table and a checklist for next week. Switch weeks, copy a plain-text summary or print it.

Example data. Fictional client, not real results.

Fields

weekAttribute. The week number to show. Defaults to the last week in the data.
publication · clientMasthead title and the client name.
desk · preparedByOptional text for the top line and the footer.
currency · localeMoney format (default USD, en-US).
weeks[].week · rangeWeek number and its date range.
weeks[].headline · leadThe lead story. The first letter becomes a drop cap.
weeks[].channels[]{ name, spend, leads, booked }. The four key figures, cost per lead and booking rate are all worked out from these rows.
weeks[].priorOptional { label, spend, leads, booked } to compare the first week against. Later weeks compare with the week before.
weeks[].highlights · lowlightsLists of short sentences.
weeks[].next[]{ text, done } checklist for the following week.
labelsOptional. Override any built-in text.

Usage

<weekly-marketing-report week="38">
  <script type="application/json">
    {
      "publication": "Weekly Marketing Report",
      "client": "Cedar Fitness Co.",
      "weeks": [
        { "week": 38, "range": "14–20 Sep 2026",
          "headline": "Newsletter lifts leads",
          "lead": "Leads reached 200…",
          "channels": [
            { "name": "Search Ads", "spend": 1310,
              "leads": 58, "booked": 17 }
          ],
          "highlights": ["…"], "lowlights": ["…"],
          "next": [{ "text": "Launch the new form" }] }
      ]
    }
  </script>
</weekly-marketing-report>

// or from data:
el.data = { client, weeks: [...] };
el.week = 40;
el.addEventListener("weekchange", e => e.detail);

Changing week fires weekchange with the week number and date range. Ticking a checklist item fires checklisttoggle. copySummary() copies a plain-text summary and fires summarycopy. The Print button uses a print stylesheet that hides the controls.
