Conversion Rate Card

A gauge that shows the conversion rate against its target, channel by channel. The what-if slider lets you try a different number of conversions and see how far it is from the target.

Example data. Not real client results.

Target

Fields

channelAttribute. The id of the channel to show, or all (default). The switch updates it.
targetAttribute. A target rate in percent that overrides every channel's own target.
eyebrow · titleOptional header text.
client · periodOptional text for the line under the title.
targetJSON. Target rate in percent for the combined "All" view (and any channel without its own).
maxTop of the gauge scale in percent. Worked out from the data if left out.
compareLabelName of the previous period, e.g. "Aug".
channels[].id · labelChannel key and button text.
channels[].visitors · conversionsCounts for the period. The rate is worked out from them.
channels[].targetOptional target rate in percent for this channel.
channels[].previousOptional { visitors, conversions } for the previous period. Adds the change in points.
showAllSet to false to hide the combined "All" view.
labels · localeOverride any built-in text; number locale (default en-US).

Usage

<conversion-rate-card channel="all">
  <script type="application/json">
    {
      "title": "Visitor to booked consultation",
      "period": "1–30 Sep 2026",
      "target": 4.8,
      "channels": [
        { "id": "organic", "label": "Organic",
          "visitors": 6420, "conversions": 244,
          "target": 4.0 },
        { "id": "paid", "label": "Paid",
          "visitors": 4180, "conversions": 196 }
      ]
    }
  </script>
</conversion-rate-card>

// or from data:
el.data = { target, channels: [...] };
el.channel = "paid";
el.addEventListener("channelchange", e => e.detail);

The "All" view adds the channels together, so every rate is worked out from the counts. Picking a channel fires channelchange with the channel, rate and target. Letting go of the slider fires whatifchange with the tested conversions, rate and gap to target.
