Client Health Score

One number for how a client account is doing, built from five weighted factors. Change how much each factor counts and the score updates as you drag. Compare it with 90 days ago to see which way it is heading.

Example data. Not real client results.

Client

Fields

periodAttribute. current or previous. The toggle updates it.
client · segmentAccount name and a short line under it.
asOf · compareDateDates for the two periods, YYYY-MM-DD.
compareLabelToggle label for the earlier period (default "90 days ago").
factors[].key · nameFactor id and display name. Four to six factors work best.
factors[].score · previous0–100 scores now and for the earlier period.
factors[].weightStarting weight, 0–10. Weights are shared as percentages of their total.
factors[].aboutWhat the factor measures. Shown when the row is hovered or focused.
factors[].note · previousNoteOptional evidence behind each period's score.
bandsOptional { healthy: 70, risk: 40 }. Below risk is Critical.

Usage

<client-health-score period="current">
  <script type="application/json">
    {
      "client": "Brightside Dental",
      "factors": [
        { "key": "engagement", "name": "Engagement",
          "weight": 5, "score": 82, "previous": 61,
          "about": "Meetings, replies and logins." }
      ]
    }
  </script>
</client-health-score>

// or from code:
el.setWeight("engagement", 8);
el.score;  // { current: 72, previous: 59 }
el.addEventListener("scorechange", e => e.detail);

The score is the weighted average of the factor scores, so each factor's share of the weights is exactly how much of the score it can move. Changing a weight, the period or resetting fires scorechange with { score, band, period, previous, weights }. resetWeights() restores the starting weights.
