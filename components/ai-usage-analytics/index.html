AI Usage Analytics

Daily AI usage by model tier, shown as tokens, requests or cost. The side panel tracks the monthly token quota and estimates the month-end bill at the current rate.

Example data. Generic model tiers and made-up prices, not a real bill.

Monthly quota

Fields

metricAttribute. tokens (default), requests or cost.
rangeAttribute. 14 or 30 days, ending on asOf.
modelAttribute. A model id to show alone; empty shows all.
models[]{ id, label, pricePerMillion } in stack order, bottom first. Up to three.
series{ [id]: { tokens: [], requests: [] } }: one number per day from start.
start · asOfISO dates of the first and last day in the series.
billingStartISO date the billing month began. Quota and cost count from here.
quotaMonthly token allowance.
budgetOptional monthly spend limit for the cost estimate.
currency · localeISO currency (default USD) and number locale (default en-US).
eyebrow · title · sourceOptional header and footer text.
labelsOptional. Override any built-in text.

Cost is tokens ÷ 1,000,000 × pricePerMillion. Month-end figures assume the daily rate so far holds for the rest of the billing month.

Usage

<ai-usage-analytics metric="tokens" range="30">
  <script type="application/json">
    {
      "start": "2026-08-26", "asOf": "2026-09-24",
      "billingStart": "2026-09-01",
      "quota": 400000000, "budget": 300,
      "models": [
        { "id": "large", "label": "Large model",
          "pricePerMillion": 6 }
      ],
      "series": {
        "large": { "tokens": [1003000, ...],
                   "requests": [932, ...] }
      }
    }
  </script>
</ai-usage-analytics>

// or from data:
el.data = { models, series, quota };
el.isolate("fast");   // null shows all
el.addEventListener("usagefilter", e => e.detail);

Every filter change (metric, range or isolated model) fires usagefilter with { metric, range, model }. Focus the chart and use the arrow keys to step through days; a hidden table holds the same numbers for screen readers.
