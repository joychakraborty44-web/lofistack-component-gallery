KPI Metrics Dashboard

Six headline numbers in one bento grid. Switch between 7, 30 and 90 days, read any sparkline point by point, and click a tile to move it into the large slot.

Example data. Not real client results.

Fields

periodAttribute or JSON. The id of the selected period (default: the first one).
heroAttribute or JSON. The id of the metric in the large slot. Clicking a tile updates it.
eyebrow · title · subtitleOptional header text.
endLast day of the data, YYYY-MM-DD. Used for the date range and point labels.
periods[]{ id, label, days, bucket }. bucket is the number of days in each sparkline point (1 = daily).
metrics[].id · labelMetric key and display name.
metrics[].formatint, currency, currency2 (two decimals) or percent.
metrics[].seriesPer period, the value of each point. The tile value is their sum.
metrics[].previousPer period, the total for the period before. Drives the change badge.
metrics[].ratio{ of, per }: two other metric ids. The value is worked out as of ÷ per for every point and for the total.
metrics[].betterup (default) or down. Sets whether a rise is shown as good or bad.
metrics[].hiddenKeeps a metric out of the grid (e.g. spend, only used by a ratio).
currency · locale · sourceNumber formatting and an optional footer note.

Usage

<kpi-dashboard period="30d" hero="revenue">
  <script type="application/json">
    {
      "end": "2026-09-30",
      "periods": [{ "id": "7d", "label": "7D", "days": 7, "bucket": 1 }],
      "metrics": [
        { "id": "leads", "label": "Leads", "format": "int",
          "series": { "7d": [27, 25, 18, 19, 27, 28, 29] },
          "previous": { "7d": 167 } },
        { "id": "cpl", "label": "Cost per lead", "format": "currency2",
          "better": "down", "ratio": { "of": "spend", "per": "leads" } }
      ]
    }
  </script>
</kpi-dashboard>

// or from data:
el.data = { end, periods: [...], metrics: [...] };
el.pin("leads");
el.addEventListener("kpiselect", e => e.detail);

Clicking a tile (or el.pin(id)) moves it into the large slot and fires kpiselect with the metric, period, value and previous value. The period buttons fire periodchange. Focus a sparkline and use the arrow keys, Home and End to read each point.
