AI Prompt Card

A saved prompt shown like a file in a code editor. Switch between versions, fill in the variables, check the filled-in preview and its rough token count, then copy it.

Example prompt. Fictional client, not a real campaign.

Load prompt

Fields

versionAttribute. The id of the version to show. The tabs update it.
modeAttribute. template shows {{variables}}; preview fills them in.
name · descriptionPrompt title and one-line purpose, shown in the title bar.
pathOptional file path shown above the editor.
model · temperatureOptional. Shown in the model chip.
activeVersionVersion shown first if no version attribute is set (default: the last one).
variables[]{ key, label, default, placeholder, suggestions }. key matches {{key}} in the text (letters, numbers, underscore).
versions[]{ id, text, updated, note } in order. updated is YYYY-MM-DD. Lines that are new since the previous version get a mark in the gutter.
labelsOptional. Override any built-in text, e.g. { "copy": "Copy" }.

Usage

<ai-prompt-card mode="preview">
  <script type="application/json">
    {
      "name": "Lead follow-up email",
      "model": "Large model",
      "variables": [
        { "key": "client_name", "default": "Brightside Dental" }
      ],
      "versions": [
        { "id": "v1", "text": "Write for {{client_name}}." }
      ]
    }
  </script>
</ai-prompt-card>

// or from data:
el.data = { name, variables: [...], versions: [...] };
el.setVariable("tone", "direct");
el.addEventListener("promptcopy", e => e.detail.text);

Copy puts the filled-in prompt on the clipboard (or selects it if the clipboard is blocked) and fires promptcopy with the text, version and counts. Tabs fire versionchange, inputs fire variablechange. Methods: setVariable(), resetVariables(), copy(), filledText(). The token count is a rough guide (characters ÷ 4).
