SEO Audit Scorecard

A site audit as a report card: one letter grade, four category scores and every issue grouped by how serious it is. Open an issue to see why it matters and how to fix it. Mark it fixed and the scores update.

Example data. Fictional site, not a real audit.

Fields

severityAttribute. Issue filter: all (default), critical, warning, notice or fixed.
categoryAttribute. Optional category id to show only that category's issues. Clicking a score card sets it.
eyebrow · title · siteHeader text. site is the domain that was audited.
pages · lastRunPages crawled and when the audit last ran (any text).
categories[]{ id, label, score, weight }. Score is 0–100 with every listed issue still open. Weight defaults to 1.
issues[].id · titleUnique key and a short, plain description of the problem.
issues[].severitycritical, warning or notice.
issues[].category · impactWhich category it belongs to, and the points fixing it adds back.
issues[].pages · urlsPages affected, and a few example paths.
issues[].why · fix"Why it matters" and "How to fix" text.
issues[].fixedOptional. true to start the issue as fixed.
source · labelsOptional footer note, and overrides for any built-in text.

Usage

<seo-audit-scorecard severity="all">
  <script type="application/json">
    {
      "site": "harborandpine.example",
      "pages": 48,
      "categories": [
        { "id": "seo", "label": "On-page SEO", "score": 71 }
      ],
      "issues": [
        { "id": "meta-desc", "severity": "warning",
          "category": "seo", "impact": 6, "pages": 14,
          "title": "Meta descriptions are missing",
          "why": "…", "fix": "…" }
      ]
    }
  </script>
</seo-audit-scorecard>

// or from data:
el.data = { site, categories: [...], issues: [...] };
el.setFixed("meta-desc", true);
el.rerun();
el.addEventListener("issuefix", e => e.detail);

Ticking "Mark as fixed" fires issuefix with the issue, its new category score, the overall score and the grade. "Re-run audit" shows a short scanning state, marks fixed issues as verified and then fires auditrun. setFixed(id, fixed) and rerun() do the same from code.
