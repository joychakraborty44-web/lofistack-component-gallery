Lead Funnel Analytics

How many people make it from visit to sale. Each stage shows its count and the share of visitors who reached it. The rate between stages shows where people drop off.

Example figures. Not real client data.

Bar scale

Fields

stages[]{ label, count } in funnel order. Two or more stages; four is typical.
eyebrow · title · subtitleOptional header text.
periodOptional date-range text, shown top right.
compareOptional { label, stages: [counts] } for the previous period. Adds a change in points to the overall rate.
sourceOptional footer note, e.g. where the data comes from.
scaleAttribute or JSON. sqrt (default) keeps small stages readable; linear draws bars exactly to scale.
labelsOptional. Override any built-in text, e.g. { "overall": "Win rate" }.
localeNumber formatting locale (default en-US).

Usage

<lead-funnel scale="sqrt">
  <script type="application/json">
    {
      "title": "Inbound pipeline",
      "period": "1 Jul – 30 Sep 2026",
      "stages": [
        { "label": "Visitors",  "count": 8640 },
        { "label": "Leads",     "count": 1296 },
        { "label": "Booked",    "count": 544 },
        { "label": "Converted", "count": 196 }
      ]
    }
  </script>
</lead-funnel>

// or from data:
el.data = { title, stages: [...] };
el.replay();  // re-run the entry animation

Every rate is worked out from the counts: each stage against the one before it, against the first stage, and overall. The summary picks out the biggest drop-off and the strongest step automatically.
