Form Conversion Card

Where people give up on a form. The mini form on the left mirrors the field-by-field bars on the right, and the field that loses the most people is highlighted in both. Switch devices to compare desktop and mobile.

Example data. Not real client results.

Fields

deviceAttribute. The key of the segment to show (all, desktop, mobile). The switch updates it.
eyebrow · title · subtitleOptional header text.
periodOptional date-range text in the footer.
form{ title, button } for the mini form.
steps[]{ id, label, type } in order. type is view, start, field or submit. Only field steps appear as inputs and can be the worst field.
segments.<key>{ label, counts, avgSeconds }. counts has one number per step: how many people reached and completed it.
tips.<stepId>Suggestion shown when that field is the worst. {rate} and {lost} are filled in.
labels · localeOptional. Override built-in text, and the number locale (default en-US).

Usage

<form-conversion device="all">
  <script type="application/json">
    {
      "title": "Home valuation request",
      "form": { "title": "Book a valuation", "button": "Send" },
      "steps": [
        { "id": "views", "label": "Form views", "type": "view" },
        { "id": "email", "label": "Email", "type": "field" },
        { "id": "submitted", "label": "Submitted", "type": "submit" }
      ],
      "segments": {
        "all": { "label": "All devices", "counts": [900, 410, 380] }
      },
      "tips": { "email": "{rate} leave at Email." }
    }
  </script>
</form-conversion>

// or from data:
el.data = { steps, segments, tips };
el.addEventListener("fieldselect", e => e.detail);

Every rate is worked out from the counts. Clicking a bar or a field in the mini form selects it and fires fieldselect with the step, counts and drop-off. The device switch fires devicechange.
