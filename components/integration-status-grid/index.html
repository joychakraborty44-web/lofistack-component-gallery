Integration Status Grid

Every tool a workspace is connected to, in one grid: whether it is working, when it last synced and how many events it has handled today. Filter by status, sync a tool now, reconnect one that dropped, or open its details.

Example data. Generic tools and a fictional client. Syncs are simulated.

Fields

integrations[].id · nameKey and display name.
integrations[].iconBuilt-in glyph: crm, card, calendar, mail, sms, chat, sheet, hub (or plug).
integrations[].statusconnected, warning or disconnected.
integrations[].issue · fixWhat is wrong, and whether sync or reconnect clears it.
integrations[].lastSyncMinutesMinutes since the last good sync. Shown as relative time and kept up to date.
integrations[].eventsTodayEvents handled since midnight.
integrations[].activityOptional. Events per hour for the last 12 hours, oldest first.
integrations[].account · connectedSince · interval · scopes[]Optional. Shown in the details drawer.
integrations[].history[]Optional. { minutesAgo, result, events, note }, with result ok or fail.
eyebrow · title · subtitle · footnoteOptional header and footer text.
filterAttribute. all, connected, warning or disconnected.

Usage

<integration-status-grid filter="all">
  <script type="application/json">
    {
      "title": "Connected tools",
      "integrations": [
        { "id": "crm", "name": "CRM", "icon": "crm",
          "status": "connected", "lastSyncMinutes": 4,
          "eventsToday": 1284 },
        { "id": "sms", "name": "SMS gateway", "icon": "sms",
          "status": "disconnected", "fix": "reconnect",
          "issue": "Sign-in expired." }
      ]
    }
  </script>
</integration-status-grid>

// methods:
el.sync("crm");  el.reconnect("sms");  el.syncAll();
el.setStatus("payments", "warning", "Webhook failing");

Sync now and Reconnect are simulated with a short delay. Each finished sync or reconnect fires integrationsync with the integration, the action, its new status and the events added. Opening details fires integrationopen, and the status filter fires filterchange.
