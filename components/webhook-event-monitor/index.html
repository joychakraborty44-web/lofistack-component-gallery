Webhook Event Monitor

A log of webhook deliveries as they arrive. Filter by status or search by event name, open any delivery to read its headers, payload and response, and replay one that failed.

Simulated events. Example data, not real client traffic.

Fields

pausedBoolean attribute. Stops the simulated stream. The Pause button toggles it.
intervalAttribute. Average milliseconds between simulated events (default 2400).
title · environmentHeader text and the environment badge.
endpointBase path shown in the header.
seed · initial · maxSeed for the repeatable simulation, events to start with, and how many rows to keep.
accountsAccount names used in simulated payloads.
simulateSet to false to show only events you add.
events[]Optional starting events: { id, name, method, path, status, latency, at, payload, response, headers }.

Usage

<webhook-monitor interval="2400">
  <script type="application/json">
    { "endpoint": "/hooks/lofistack", "environment": "Production" }
  </script>
</webhook-monitor>

// feed it real deliveries:
el.addEvent({ name: "invoice.paid", method: "POST",
  path: "/hooks/payments", status: 200, latency: 84,
  payload: { invoice: { id: "inv_1042" } } });
el.pause();  el.resume();
el.addEventListener("webhookreplay", e => e.detail);

Replay re-sends the selected delivery as a new row marked "replay" and fires webhookreplay with the original and the new event. Selecting a row fires eventselect; Pause and Resume fire streamchange. The stream starts paused when reduced motion is on, and skips ticks while the tab is hidden.
