Ad Creative Performance

Every ad creative in a campaign, with its format and results. Sort the gallery by CTR, cost per conversion, spend or conversions, filter by format, and pick two creatives to see which one wins on each metric.

Example data. Not real client results.

Fields

sortAttribute. ctr (default), cpa, spend or conversions. The sort buttons update it.
formatAttribute. all (default), image, video or carousel.
currency · localeAttribute or JSON. Money and number formatting (default USD, en-US).
eyebrow · title · subtitle · periodOptional header text.
creatives[].id · nameUnique key and display name.
creatives[].formatimage, video or carousel. Video takes duration, carousel takes slides.
creatives[].copyOptional ad text, shown under the name.
creatives[].impressions · clicks · spend · conversionsRaw counts. CTR, cost per click, conversion rate and cost per conversion are worked out from these.
creatives[].art{ pattern, invert, text }. Pattern is sun, stripes, dots, arch, blocks, wave or type. A stand-in for the real thumbnail.
sourceOptional footer note.
labelsOptional. Override any built-in text.

Usage

<ad-creative-performance sort="ctr" format="all">
  <script type="application/json">
    {
      "title": "New-patient offer",
      "currency": "USD",
      "creatives": [
        { "id": "smile-30", "name": "Smile in 30 days",
          "format": "video", "duration": "0:15",
          "impressions": 182400, "clicks": 3612,
          "spend": 2140, "conversions": 96,
          "art": { "pattern": "sun" } }
      ]
    }
  </script>
</ad-creative-performance>

// or from data:
el.data = { title, creatives: [...] };
el.compare(["smile-30", "before-after"]);
el.addEventListener("creativecompare", e => e.detail);

Picking creatives to compare fires creativecompare with the chosen ids, each one's metrics and the overall winner. Changing the sort or format fires creativesort. Use compare(ids) and clearCompare() to drive the comparison from code.
