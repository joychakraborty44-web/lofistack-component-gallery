Campaign Status Card

Where a campaign is in its life, from draft to finished. It shows how far through its dates it is, whether spend is on pace, and every status change. The controls only allow moves that make sense right now.

Example data. Not real client results.

Start from

Fields

statusAttribute or JSON. draft, scheduled, live, paused or completed. Kept in sync as the state changes.
name · client · idCampaign name, client and reference.
objective · ownerOptional details under the title.
todayDate used for flight and pacing maths, YYYY-MM-DD (default: the real date).
flight{ start, end } dates, both days included.
budget · spentTotal budget and spend so far. Pacing compares spend with the budget share expected by today.
currency · localeMoney format (default USD, en-US).
channels[]{ name, type, spent, leads }. type picks the glyph: search, social, video, display, email.
log[]Past changes, oldest first: { action, by, at }. Actions: created, scheduled, launched, paused, resumed, ended.
userName recorded for changes made in the card (default "you").

Usage

<campaign-status status="live">
  <script type="application/json">
    {
      "name": "Fall Smile Makeover",
      "client": "Brightside Dental",
      "flight": { "start": "2026-09-22", "end": "2026-10-21" },
      "budget": 12000, "spent": 4520,
      "channels": [
        { "name": "Search Ads", "type": "search", "spent": 2080, "leads": 61 }
      ]
    }
  </script>
</campaign-status>

// or from code:
el.can("pause");        // true when live
el.transition("pause");
el.addEventListener("statuschange", e => e.detail);

Allowed moves: Draft → Scheduled or Live; Scheduled → Live; Live ⇄ Paused; any started state → Completed (asks to confirm first). Each move adds a log entry and fires statuschange with { from, to, action, by, at }. Launching before the planned start moves the flight start to today.
