Team Member Performance

A sales leaderboard with a top-three podium and a ranked list. Rank the team by deals won, revenue, calls or response time, for this week or this month. Open a person to see their trend and how close they are to each target.

Example data. Fictional team, not real results.

Team size

Fields

metricAttribute. deals, revenue, calls or response. The "Rank by" switch updates it.
periodAttribute. A key of periods, e.g. week or month.
eyebrow · title · teamOptional header text.
currency · localeRevenue currency (default USD) and number locale (default en-US).
periods.<key>{ label, range, compare, axis }. axis names the points of each trend, oldest first.
members[].id · name · rolePerson key, name and job title. Initials are made from the name.
members[].periods.<key>Arrays for deals, revenue, calls and response (minutes), oldest first. The last value is the current period, the one before it the previous period.
…target{ deals, revenue, calls, response } for that period. Response is a maximum.
labelsOptional. Override any built-in text.

Usage

<team-performance metric="revenue" period="week">
  <script type="application/json">
    {
      "title": "Team performance",
      "periods": { "week": { "label": "This week",
        "compare": "last week",
        "axis": ["W38", "W39"] } },
      "members": [
        { "id": "mo", "name": "Maya Okafor",
          "periods": { "week": {
            "deals": [6, 5], "revenue": [14750, 11250],
            "calls": [60, 68], "response": [14, 16],
            "target": { "revenue": 12000 } } } }
      ]
    }
  </script>
</team-performance>

// or from data:
el.data = { periods, members: [...] };
el.metric = "deals";
el.addEventListener("memberselect", e => e.detail);

Ranks and the ▲▼ change are worked out by comparing the last two values of each array. Opening a person fires memberselect with their id, rank, metric and period. Changing the ranking fires sortchange; changing the period fires periodchange.
