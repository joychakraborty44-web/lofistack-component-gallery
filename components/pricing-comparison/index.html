Pricing Comparison Card

Three plans side by side, with a switch between monthly and yearly billing. One plan is highlighted as the recommended choice. Every plan, price and feature comes from a small block of JSON.

Example plans. Not real pricing.

Popular plan

Fields

billingAttribute. monthly or yearly. The switch updates it.
featuredAttribute. The id of the plan to highlight.
currencyAny ISO currency code (default USD). Attribute or JSON.
eyebrow · title · subtitleOptional header text.
footnoteOptional line under the plans.
tiers[].id · namePlan key and display name.
tiers[].descriptionOne-line summary of who the plan is for.
tiers[].price{ monthly, yearly }, both per month. Yearly is the per-month price when billed yearly. Use null with priceLabel (e.g. "Custom") for quote-only plans.
tiers[].priceNoteOptional. Replaces the billing line under the price.
tiers[].cta{ label, href }. Without href it renders a button.
tiers[].featuresStrings are included. { text, included: false } shows as not included.
tiers[].badgeLabel on the highlighted plan (default "Most popular").

Usage

<pricing-compare billing="monthly" featured="growth">
  <script type="application/json">
    {
      "title": "Plans that grow with you",
      "currency": "USD",
      "tiers": [
        {
          "id": "growth", "name": "Growth",
          "description": "For small teams.",
          "price": { "monthly": 79, "yearly": 64 },
          "cta": { "label": "Choose Growth", "href": "/signup" },
          "features": ["5 workspaces",
            { "text": "SSO", "included": false }]
        }
      ]
    }
  </script>
</pricing-compare>

// or from data:
el.data = { title, currency, tiers: [...] };
el.addEventListener("planselect", e => e.detail);

The yearly "Save" label is worked out from the plan prices. Clicking a plan's button fires a planselect event with the plan, billing period and price. Changing the switch fires billingchange.
