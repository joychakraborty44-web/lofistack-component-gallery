Task Progress Board

A kanban board for client work. Drag cards between columns, or focus a card and use the arrow keys. Column counts and the progress bar update as you go, and the chips filter the board by assignee.

Example data. Not real client work.

Fields

assigneeAttribute. A person id to filter the board, or all (default). The chips update it.
eyebrow · title · subtitleOptional header text.
todayOptional YYYY-MM-DD used to mark due dates as overdue, today or tomorrow. Defaults to the real date.
columns[]{ id, label, tone } in board order. tone is slate, blue, amber or green.
columns[].limitOptional work-in-progress limit. The count turns red when a column goes over it.
columns[].doneMarks the column that counts as finished (default: the last column).
people[]{ id, name }. Initials and avatar colours are worked out from the name.
tasks[].id · titleTask key (shown on the card) and title.
tasks[].statusThe id of the column the task sits in.
tasks[].assigneeA person id.
tasks[].dueDue date as YYYY-MM-DD.
tasks[].priorityhigh, medium or low.
tasks[].checklist{ done, total } sub-task progress.
labelsOptional. Override any built-in text, e.g. { "progress": "Sprint progress" }.

Usage

<task-board assignee="all">
  <script type="application/json">
    {
      "title": "Website relaunch",
      "columns": [
        { "id": "todo", "label": "To do", "tone": "slate" },
        { "id": "done", "label": "Done", "tone": "green", "done": true }
      ],
      "people": [{ "id": "mc", "name": "Maya Chen" }],
      "tasks": [
        { "id": "BD-148", "title": "Write FAQ copy", "status": "todo",
          "assignee": "mc", "due": "2026-10-07", "priority": "medium",
          "checklist": { "done": 0, "total": 4 } }
      ]
    }
  </script>
</task-board>

// or from data:
el.data = { columns, people, tasks };
el.moveTask("BD-148", "done");
el.addEventListener("taskmove", e => e.detail);

Moving a card by drag, arrow key, the Move menu or moveTask() fires a taskmove event with the task, the old and new column, the new position and the progress. Changing the assignee filter fires taskfilter. el.tasks returns the current tasks.
