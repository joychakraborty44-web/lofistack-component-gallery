AI Agent Status Panel

An ops console for a team of AI agents. Each agent shows its status, current task, queue, success rate and recent throughput. You can start, pause or restart any agent, and open an error to retry it.

Example data. Simulated agents, not a real system.

Fields

filterAttribute. all, running, idle, error or paused. The filter buttons update it.
pausedBoolean attribute. Stops live updates. The Pause button toggles it.
intervalAttribute. Milliseconds between live updates (default 2000, minimum 500).
path · title · subtitleOptional header text.
seedNumber that makes the simulated updates repeat the same way each time.
agents[].id · name · modelAgent key, display name and model label.
agents[].statusrunning, idle, error or paused.
agents[].taskWhat the agent is working on.
agents[].queueItems waiting.
agents[].processed · succeededItem counts. Success rate is succeeded ÷ processed.
agents[].load · failRateSimulation only: average items per update, and the share that fail.
agents[].error{ code, at, message } shown when an error row is opened.
labels · localeOverride any built-in text; number and time locale (default en-GB).

Usage

<agent-status-panel interval="2000">
  <script type="application/json">
    {
      "title": "Agent fleet",
      "agents": [
        { "id": "agt-01", "name": "Lead Qualifier",
          "status": "running", "task": "Scoring leads",
          "queue": 14, "processed": 1286,
          "succeeded": 1262, "load": 3 }
      ]
    }
  </script>
</agent-status-panel>

// or from data, and control it:
el.data = { agents: [...] };
el.setStatus("agt-01", "error", "Timed out");
el.paused = true;
el.addEventListener("agentaction", e => e.detail);

Start, Pause, Restart and Retry fire an agentaction event with the agent, the action and the status before and after. setStatus(id, status, message) changes an agent from code. Live updates stop while the tab is hidden, and when you press Pause.
