Client Overview Card

One client at a glance: account health, monthly revenue, tenure and open pipeline. Tabs hold the account details, the people you talk to, and a running set of notes.

Example data. Fictional client, not real results.

Health

Fields

tabAttribute. overview, contacts or notes. The tabs update it.
favouriteBoolean attribute (or JSON). The star button toggles it.
healthAttribute. Overrides health.status: healthy, at-risk, critical.
company · initialsClient name. Initials are worked out from the name if left out.
industry · location · websiteOptional details under the name and in the Overview tab.
plan · billing · renewalPlan name, billing text and renewal date (ISO).
owner{ name, role } of the account owner.
health{ status, score, note }. Score is 0–100; the note shows in Overview.
mrr · mrrPreviousMonthly recurring revenue, and the earlier figure for the change. mrrCompareLabel names it.
currency · localeISO currency (default USD) and number/date locale (default en-GB).
clientSince · asOfISO dates. Tenure and "days ago" are counted to asOf (default: today).
lastActivity{ date, summary }.
services[]Strings, shown as chips.
opportunities[]{ name, stage, value, close }. stages[] sets the stage order (default Discovery → Closing).
contacts[]{ name, role, email, phone, primary }.
notes[]{ author, date, text }, newest first. noteAuthor names who adds new notes (default "You").

Usage

<client-overview tab="overview" favourite>
  <script type="application/json">
    {
      "company": "Harbor & Pine Realty",
      "plan": "Growth retainer",
      "owner": { "name": "Maya Okafor" },
      "health": { "status": "healthy", "score": 82 },
      "mrr": 4800, "mrrPrevious": 4200,
      "clientSince": "2024-03-11",
      "contacts": [{ "name": "Dana Whitfield",
        "email": "dana@harborandpine.example" }],
      "notes": []
    }
  </script>
</client-overview>

// or from data:
el.data = { company, mrr, contacts: [...] };
el.addNote("Sent the Q4 plan");
el.addEventListener("noteadd", e => e.detail.note);

Adding a note fires noteadd with the note and the new count. The star fires favouritechange, the tabs fire tabchange and copying an email fires emailcopy. Notes live in memory only; save them from the event.
